03 / Palette

色彩

以 iOS 系统蓝为锚点，向靛蓝与天青两端延伸。标志渐变只在这三者之间过渡；界面仍使用项目现有的语义令牌。点击色块可复制色值。

04 / Typography

字体

字标是定制的几何单线体：小写、圆头端点、在 x-height 上与图形标同频。界面文字沿用项目令牌里的系统字体栈，不下载 Web 字体，首屏无 FOUT。

05 / Usage

使用规则

保持标志的完整性与留白。图形标与字标的关系已经调好，不要重新拼版；需要单色场景时使用白色单色标。

清晰空间

图形标四周至少留出 x 的空白，x = 图形标高度的 1/4。横版标志同理，以图形标高度为基准。

icon 16
mark 24
lockup 160

最小尺寸

图标不小于 16px；彩色图形标不小于 24px；横版标志宽度不小于 160px。再小请只使用图标。

禁止

  • 拉伸或压缩比例
  • 改变渐变方向
  • 加投影、描边、发光
  • 在复杂背景上直接用彩色标
